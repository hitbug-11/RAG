# 概念笔记

本目录存放可长期复用的原子概念笔记。新概念应先说明它在 RAG 流程及已有知识中的定位，再讲机制、公式、代码与版权研究作用。

计划中的首批概念：

- Embedding 与语义空间；
- Sparse/Dense/Hybrid Retrieval；
- Top-k、Recall、MRR 与 nDCG；
- Reranker；
- Context Packing；
- 参数知识与检索知识冲突；
- 黑盒所有权验证；
- Watermark Removal 与 Spoofing。

创建新笔记时使用 [概念模板](../templates/concept-note-template.md)。
