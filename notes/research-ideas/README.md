# 研究问题

## 当前优先方向

1. 现代 Retriever 与 Reranker 下知识库水印的迁移性；
2. Query Rewrite、Multi-query、Context Compression 和 Adaptive Routing 的天然去水印效应；
3. 不依赖公开 CoT 的黑盒知识库版权验证；
4. 局部盗用比例、验证查询量与统计功效的关系；
5. 同时抵抗水印去除、伪造和所有权歧义的多比特水印。

## 记录原则

每个研究问题应包含：

- 与现有工作的差异；
- 明确威胁模型；
- 可证伪假设；
- 最小实验；
- 主要指标；
- 潜在负面结果；
- 下一步决策条件。
